# User Stories – Läslistan

## 1. Katalog

**User Story**

Som användare vill jag kunna se böckerna i katalogen så att jag kan välja vilka böcker jag vill läsa.

**Funktionella krav**
- Användaren ska kunna se böckerna i katalogen.
- Användaren ska kunna markera en bok som favorit.
- Användaren ska kunna ta bort en favoritmarkering genom att klicka på hjärtat igen.

## 2. Lägg till bok

**User Story**

Som användare vill jag kunna lägga till en bok med författare och titel så att nya böcker kan läggas till i katalogen.

**Funktionella krav**
- Användaren ska kunna fylla i författare och titel.
- Användaren ska kunna lägga till en bok.
- Den tillagda boken ska visas i katalogen.
- Knappen för att lägga till en bok ska vara inaktiverad när formulärets fält är tomma.

## 3. Mina böcker

**User Story**

Som användare vill jag kunna se mina favoritböcker så att jag enkelt kan hitta de böcker jag har valt ut.

**Funktionella krav**
- Användaren ska kunna se sina favoritmarkerade böcker.
- En bok som tas bort från favoriter ska inte längre visas i listan över favoritböcker.
